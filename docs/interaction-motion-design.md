# 页面交互动效设计

状态：已确认。

## 目标

为全站建立一致、克制的交互反馈语言。动效用于说明状态变化、空间关系和操作结果，不用于装饰普通内容，也不应拖慢聊天与语音等高频操作。

## 已确认范围

- 覆盖全局交互反馈，而非只修补少数弹窗与菜单。
- 重点考虑弹层进出、移动端抽屉、Toast、菜单、页签内容和列表增删等当前瞬时变化。
- 保留现有按钮颜色反馈、服务器图标悬停反馈与加载旋转，并在后续设计中统一节奏。

## 视觉性格与节奏

整体采用快速、克制、有方向感的动效，不使用弹跳、橡皮筋、持续漂浮等装饰性效果。

- 即时反馈约 `100ms`，用于按钮、开关和微小状态变化。
- 浮层反馈约 `160ms`，用于菜单、个人信息卡片与 Toast。
- 空间切换约 `220ms`，用于弹窗、面板与移动端抽屉。
- 进入过程可以稍柔和；退出过程应更快，避免阻碍下一次操作。

## 减少动态效果

自动遵循操作系统的 `prefers-reduced-motion` 偏好，不增加应用内独立开关。

- 取消位移、缩放与列表位置移动。
- 弹层只保留极短的透明度过渡。
- 加载状态以低频明暗变化替代持续旋转，保证状态仍然可辨认。

## 实时内容

- 仅对实时到达的新消息做一次轻微淡入。
- 历史消息、首次加载内容和滚动虚拟列表不使用进入动效。
- 语音参与者加入或离开时使用短暂淡入淡出，并平滑归位其余参与者。
- 动效只提示新发生的变化，不能把数据加载或列表复用表现成实时事件。

## 空间关系

- 锚定菜单与个人信息卡片从触发点所在方向轻微展开。
- 居中弹窗由中心淡入并小幅上移。
- 移动端频道栏从左侧滑入，成员栏从右侧滑入。
- Toast 从页面顶部进入。
- 关闭时沿进入方向更快返回。

## 控件反馈

- 可点击按钮按下时轻微缩小到约 `98%`，松开后立即恢复。
- 开关、静音状态、主题色选中标记平滑切换颜色与图标状态。
- 禁用控件不提供按压反馈。
- 文字频道、页签等密集导航项只过渡背景与选中指示，不缩放整个条目。

## 内容切换

- 页签内容使用约 `100ms` 的淡入，不做整页横向滑动。
- 删除确认、设备错误、权限操作区等局部条件内容短暂淡入，并小幅展开高度。
- 点击后立即切换内容状态，动效不得延迟新内容进入可操作状态。

## 连续操作

- 所有动效都可中断，并始终以最新交互状态为准。
- 退出中的浮层立即停止接收点击。
- 快速开关抽屉、菜单或页签时不排队播放历史动效。
- 当视觉连续性与操作响应冲突时，优先保证操作响应。

## 语音状态

- 正在说话的边框或状态色只做极短平滑过渡，紧跟实际音量，不使用循环脉冲。
- 连接中保留旋转加载标识；在减少动态效果模式下改用低频明暗变化。
- 麦克风静音、耳机静音与已连接状态只在状态切换瞬间过渡一次。

## 普通列表

- 服务器、频道、成员、邀请码等普通列表只为单项且用户可感知的增删与位置变化提供动效。
- 首次加载、整批刷新和服务器切换后的列表替换不播放逐项动画。
- 消息列表继续遵循实时内容的专用规则，不套用普通列表动效。

## 操作结果

- 成功与失败通过 Toast 的进入退出动效呈现，不使用庆祝、抖动或闪烁。
- 表单错误短暂淡入，并将焦点移到相关控件。
- 危险操作依靠确认步骤、颜色与文案表达严重性，不用动效制造紧迫感。

## 实现边界

不引入动画库，使用 Vue 自带的 `Transition`、`TransitionGroup` 与集中式 CSS 实现。

- 在全局样式中集中定义时长、缓动、位移距离及减少动态效果规则。
- 组件声明弹层、抽屉、Toast、内容或列表等语义类别，不自行发明时长与缓动。
- 共享过渡规则保持简单；只有锚点方向、左右抽屉等空间差异由组件提供方向信息。
- 当前需求不包含手势跟随、拖拽排序、弹簧物理、共享元素转场或复杂时间线，不为这些潜在需求预先增加依赖。

## 组件映射

- **锚定浮层**：用户账户菜单、服务器/频道/消息操作菜单、语音参与者操作菜单、语音设备菜单、个人信息卡片及音量类 Popover。
- **居中弹层**：用户设置、服务器管理、平台管理、平台服务器管理、更新日志、图片裁剪、退出登录与离开服务器确认。
- **移动端抽屉**：左侧频道栏与右侧成员栏，遮罩同步淡入淡出。
- **顶部反馈**：Toast 单项进出与堆栈归位。
- **内容切换**：登录/注册、设置与管理页签、音频子页签以及局部条件反馈区。
- **实时内容**：实时新消息与语音参与者变化。
- **普通列表**：服务器、频道、成员与邀请码等单项变化。
- **控件状态**：按钮按压、开关、静音、主题选中态与语音状态。

## 桌面成员栏

- 桌面端成员栏收起或展开时淡入淡出，聊天区在约 `220ms` 内平滑扩展或收缩。
- 消息内容只随容器宽度自然重排，不逐条播放位移动画。
- 减少动态效果模式下直接切换布局。

## 验收

- 桌面与移动端分别验证浮层、抽屉、页签、Toast、列表和控件反馈。
- 验证快速连续开关时只呈现最新状态，退出元素不会继续拦截点击。
- 验证首次加载、批量刷新、历史消息和虚拟滚动不会误触发逐项动效。
- 在 `prefers-reduced-motion: reduce` 下验证位移、缩放、列表移动与持续旋转均已退化。
- 运行前端类型检查、单元测试、构建与相关 Playwright 场景。
