# 用户设置快捷入口设计

## 背景

当前用户设置只能从服务器栏底部头像打开的账户菜单进入，需要先打开菜单再点击“用户设置”。用户设置面板本身同时承载账号、音频、音效和主题设置，是跨服务器的全局用户设置空间。

## 决策

- 在服务器栏底部账户区域、头像按钮正上方增加独立的齿轮图标按钮。
- 齿轮按钮只显示图标，提供 `title` 和 `aria-label="用户设置"`；桌面端和移动端均显示。
- 点击齿轮直接打开现有用户设置面板的“账号”页。
- 头像账户菜单中的“用户设置”项继续保留，并打开同一个面板的“账号”页。
- 从齿轮打开面板后关闭或按 `Esc`，焦点返回齿轮；从头像菜单打开则返回头像按钮。

## 范围

本次只调整用户设置的访问路径和必要的焦点管理，不修改设置面板的内容、页签顺序、保存逻辑或头像账户菜单的既有操作。

## 验收条件

1. 登录后，服务器栏底部头像上方可见用户设置齿轮按钮。
2. 齿轮按钮在桌面端和移动端均可通过鼠标、触摸和键盘操作，并具有“用户设置”的可访问名称。
3. 点击齿轮后，用户设置面板从“账号”页打开。
4. 头像账户菜单仍显示并可操作“用户设置”项。
5. 两种入口打开的都是同一个用户设置面板；关闭或按 `Esc` 后分别恢复到对应触发按钮。
6. 现有设置面板和头像账户菜单的其他行为不变。

## 实现与验证

- 复用现有 `ProfilePanel`、设置入口处理和 `Settings` 图标，不引入新的设置状态。
- 为服务器栏入口补充 E2E 覆盖，并保留头像菜单路径的既有覆盖。
- 运行前端类型检查、构建和相关 Playwright 测试。
