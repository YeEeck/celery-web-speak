# WebUI 右键菜单策略

## 背景

WebUI 已在服务器、频道和音频设备等对象上提供应用内右键菜单，但其他按钮、面板和空白区域仍会显示浏览器默认菜单。多数默认菜单项与当前操作对象无关，会削弱界面的一致性；与此同时，文本编辑和内容复制仍可能依赖浏览器原生能力。

## 已确定原则

- 应用操作面默认抑制浏览器右键菜单。
- 只有浏览器菜单能为当前目标提供明确用户价值时才保留。
- 规则应以元素能力和交互语义定义，而不是按页面维护禁用名单，使新增界面默认遵循同一策略。
- 承载文本值的输入控件始终保留浏览器右键菜单，包括密码框、聊天输入框、管理表单中的文本输入，以及未来可能出现的 `contenteditable` 区域；不要求控件内已经存在文本选区，`readonly` 或 `disabled` 状态也不取消例外。复选框、滑块、文件选择等非文本输入不属于该例外。
- 只读文本仅在存在非空选区、且右键位置命中该选区时保留浏览器菜单。消息正文、用户名和其他只读文案遵循相同规则；页面其他位置残留的选区不能使当前目标获得原生菜单。
- 具有真实导航地址的链接及其子元素始终保留浏览器右键菜单，以提供新标签页打开和复制地址等原生能力；仅触发应用动作的按钮不因视觉样式类似链接而获得例外。
- 图片、视频和音频只有在属于用户内容时才保留浏览器右键菜单。产品 Logo、头像、图标和其他界面素材仍属于应用操作面，不因所用 HTML 标签获得例外。
- 策略覆盖 WebUI 的加载页、连接错误页、登录/注册页和登录后的主界面；各阶段使用相同的例外规则。
- 已有应用内右键菜单的触发区域始终由自定义菜单优先，其后代不能通过只读文本选区等原生例外覆盖该菜单。同一右键目标不得混用两套菜单语义；若未来需要嵌入可编辑控件或真实链接，应先拆分交互结构。
- 全局抑制仅治理桌面鼠标右键，不接管移动端触摸长按，也不抑制键盘主动请求的浏览器菜单。已有应用内菜单继续支持菜单键和 `Shift+F10`。
- 是否进入全局策略由实际输入来源决定，不由视口宽度或设备名称决定。鼠标在窄窗口或移动设备上仍按鼠标处理，触摸和触控笔在桌面设备上仍保留原生行为。
- 普通按钮、面板和空白区域被抑制后直接无动作，不显示提示，也不提供空的应用菜单；产品操作必须由可见控件或有实际内容的自定义菜单承载。
- 抑制浏览器菜单也会隐藏该区域由浏览器扩展注入的菜单项。此取舍可接受，因为文本编辑、真实链接、选中的只读文本和用户内容媒体等主要扩展使用场景仍保留原生菜单。

## 判定顺序

桌面鼠标触发 `contextmenu` 时按以下顺序处理：

1. 事件已经被现有组件接管时，保留组件的应用内菜单，不再执行全局判断。
2. 目标位于承载文本值的输入控件、真实链接或显式标记的用户内容媒体内时，保留浏览器菜单。
3. 当前存在非空只读文本选区，且事件坐标实际命中该选区时，保留浏览器菜单。
4. 其他目标调用 `preventDefault()`，不显示任何替代反馈。

移动端触摸、触控笔和键盘触发的 `contextmenu` 不进入上述全局判断。自定义菜单组件现有的键盘入口不受影响。

## 实现边界

- 在 WebUI 根级集中安装策略，组件不逐页重复注册禁用逻辑。
- 全局处理器在冒泡阶段运行，并先检查 `defaultPrevented`，确保服务器、频道和设备菜单优先。
- 文本控件按输入能力判断，覆盖 `textarea`、`contenteditable` 和承载可编辑文本或数值的 `input`；复选框、单选框、滑块、颜色、文件和按钮类输入不在其中。
- 真实链接按带有导航地址的 `a` 元素判断。
- 未来用户内容媒体通过明确的语义标记选择加入原生菜单例外；不得把所有 `img`、`video` 或 `audio` 自动列为例外。
- 只读文本选区必须使用事件坐标做命中测试，不能只判断页面是否存在选区。
- 策略只影响菜单展示，不禁止文本选择，也不改变复制、粘贴和键盘快捷键。

## 验收标准

1. 鼠标右键点击普通按钮、面板、空白区域、Logo、头像或图标时，浏览器默认菜单被抑制且没有替代提示。
2. 鼠标右键点击文本输入框、密码框、文本域、只读或禁用的文本控件时，浏览器菜单不被抑制。
3. 选中消息或其他只读文本后，在选区内右键保留浏览器菜单；在选区外右键仍抑制。
4. 真实链接和显式标记的用户内容媒体保留浏览器菜单，普通界面素材不保留。
5. 服务器、频道和音频设备的应用内菜单继续正常打开，并维持现有鼠标和键盘行为。
6. 触摸长按、触控笔和普通区域上的键盘菜单请求不被全局策略抑制。
7. 加载页、连接错误页、认证页和主界面执行同一策略。
8. 自动化测试覆盖判定规则与现有自定义菜单回归；桌面和移动端各进行一次浏览器验证。

## 文档归属

这是一项易于调整的 WebUI 交互策略，不满足架构决策记录的长期锁定条件，因此不创建 ADR。本文使用的“应用操作面”“原生菜单例外”等属于通用界面概念，不加入产品领域词汇表。
