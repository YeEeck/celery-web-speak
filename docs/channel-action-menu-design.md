# 频道右键菜单

## 背景

服务器内的语音频道和文字频道目前没有右键菜单，浏览器会显示与应用无关的默认菜单。
频道操作也只能通过左键进入频道或进入完整的服务器管理面板完成，缺少一致、就近的频道信息与管理入口。

## 设计决策

- 语音频道和文字频道都提供“复制频道名称”。复制原始频道名称，不附加频道类型符号或服务器名称。
- 文字频道额外提供“标记为已读”。该项始终显示；频道没有未读消息时使用禁用态，不通过显隐改变菜单布局。
- 频道菜单不提供打开、加入、切换、取消连接或断开操作。频道导航与语音连接继续由现有左键操作和连接面板负责。
- 服务器所有者和服务器管理员额外看到“编辑频道”。该操作打开服务器管理面板的频道页，并预选触发菜单的频道。
- 平台管理员不会仅凭平台角色获得“编辑频道”，必须同时在当前服务器内具有所有者或管理员角色，与后端频道管理权限保持一致。
- 删除频道继续保留在频道管理页的名称确认流程中，不提升到右键菜单。

## 菜单结构

成员操作按以下顺序排列：

1. 复制频道名称。
2. 标记为已读，仅文字频道显示；没有未读消息时禁用。

有频道管理权限时，在成员操作之后增加分隔线和“编辑频道”。

## 交互与反馈

- 鼠标右键在指针位置打开菜单，同时阻止浏览器默认菜单。
- 频道行支持键盘菜单键和 `Shift+F10`，菜单打开后聚焦第一个可用菜单项。
- 菜单支持方向键、`Home`、`End`、`Escape` 和 `Tab`；禁用项不参与键盘聚焦。
- 点击菜单外、滚动或调整窗口尺寸时关闭菜单。
- 切换服务器或目标频道被删除时关闭菜单。
- 复制完成后关闭菜单，并在视口顶部居中显示约两秒的非阻塞提示。成功文案为“频道名称已复制”，失败文案为“复制失败，请重试”。提示通过无障碍状态区域播报。
- 触发右键菜单本身不改变当前文字频道，也不触发语音连接状态变化。

## 验收标准

1. 语音和文字频道均可通过鼠标右键、菜单键和 `Shift+F10` 打开应用内频道菜单。
2. 两类频道都显示“复制频道名称”，并复制未经修饰的频道名称。
3. 文字频道始终显示“标记为已读”；无未读时禁用，有未读时可清除该频道的未读状态，且不会切换当前频道。
4. 普通成员看不到“编辑频道”；所有者和服务器管理员可通过该项直接进入目标频道的设置页。
5. 菜单不包含频道导航、语音连接或删除操作。
6. 菜单在视口边缘保持完整可见，并与现有服务器右键菜单的视觉和键盘行为一致。
7. 复制反馈显示约两秒，不遮挡频道列表、聊天输入框或底部语音控制。
