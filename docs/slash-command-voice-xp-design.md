# 斜杠指令与服务器语音经验设置设计

日期：2026-07-31
状态：accepted

## 问题

服务器管理者目前只能依赖数据库或 Shell 直接调整成员的服务器语音经验。产品需要一个类似游戏命令的轻量入口，同时希望未来普通成员也能通过同一交互方式触发非消息行为。

本设计将斜杠指令作为消息编辑器中的一等交互方式。第一版只交付服务器语音经验查询与绝对设置，不新增独立控制台页面，也不把平台管理或部署运维迁入聊天入口。

## 产品边界

- 斜杠指令是非消息操作，所有用户共用；管理员指令只是受权限限制的一类。
- 指令作用于提交者自身、当前服务器或当前频道，不承载平台级管理。
- 第一版必须进入当前服务器的某个文字频道才能使用指令；服务器没有文字频道时，需要先通过现有管理控制台创建文字频道。
- 文字频道只是入口。`/xp` 的作用域是当前服务器，与触发它的具体文字频道无关。
- 文字禁言只限制公开文字内容，不阻止只产生私有反馈的斜杠指令。

## 首版指令

```text
/xp get
/xp get @username
/xp set @username <xp>
```

### 查询

- `/xp get` 查询提交者本人。
- `/xp get @username` 查询当前服务器中的指定活跃成员。
- 当前服务器的所有成员都可以查询自己或其他活跃成员；该信息已经通过同服个人信息接口可读。
- 成功反馈显示总 XP、当前等级和本级进度，例如：`@alice：120 XP · Lv.2 · 本级 0/90 XP`。

### 设置

- `/xp set` 是绝对设置，不表示增加或扣减。
- 目标成员不能省略。
- XP 必须是 `0` 到 `1,000,000,000` 之间的整数，包含两端；`0` 表示重置经验。
- 不接受负数、小数、单位后缀或范围外数值。
- 设置只改变执行事务中的当前总 XP，不冻结经验。成员此后继续按正常语音时长累计 XP。
- 成功反馈显示修改前后总 XP 与等级，例如：`已将 @alice 的服务器语音经验从 80 XP（Lv.1）设置为 120 XP（Lv.2）。`
- 成功后清空消息编辑器；参数错误、目标不存在、权限不足或服务端失败时保留原输入以便修改。
- 设置按 Enter 后立即执行，不增加二次确认、命令历史或上箭头恢复。

`/xp add` 不在第一版范围内。未来若需要奖励或扣减，必须通过显式的 `add` 子命令增加，不能让省略动词的语法同时表示总值与增量。

## 输入规则

- 去除输入首尾空白后，以单个 `/` 开头的输入始终作为指令处理。
- 未知指令、未知子命令或错误参数只返回私有反馈，绝不退化为频道消息。
- 以 `//` 开头表示发送普通消息，并在最终消息中移除一个前导斜杠。例如 `//xp get` 在频道中显示为 `/xp get`。
- 命令词大小写不敏感，界面统一展示小写规范写法。
- 参数之间允许一个或多个空白字符。
- 成员参数必须使用 `@登录名`。登录名匹配沿用现有大小写不敏感规则，反馈显示账号保存的原始写法。
- 不接受显示名称、数字用户 ID、引号、选择器或额外位置参数。

## 提示与补全

- 输入 `/` 后显示当前用户可用的指令与简短参数提示。
- 输入 `/xp get @` 或 `/xp set @` 后，从当前服务器活跃成员中按登录名过滤和补全。
- 提示层支持鼠标、触摸、方向键、Enter、Tab 和 Escape。
- 普通成员的提示中不展示 `/xp set`，但服务端权限校验仍是唯一安全依据。
- 第一版不增加 `/help`；未知指令反馈同时展示当前可用指令。

## 成员范围与权限

目标只能是当前服务器的活跃成员。被临时或永久封禁、已移出或从未加入的账号不参与补全；手动输入这些账号或不存在的全局登录名时，统一反馈“当前服务器中找不到该成员”，不泄露平台账号是否存在。

`/xp get` 对当前服务器所有成员开放。`/xp set` 沿用现有服务器成员管理层级：

- 服务器所有者可以设置自己、服务器管理员和普通成员。
- 普通服务器管理员只能设置普通成员，不能设置自己、所有者或其他管理员。
- 平台管理员必须先显式加入当前服务器。加入后可以设置自己、普通成员和服务器管理员，但不能设置服务器所有者。
- 所有权限都由服务端重新校验；前端提示与补全不构成安全边界。

第一版不增加命令专属 ACL。未来若需要更细的管理角色，应扩展统一的服务器权限模型，并由管理界面与斜杠指令共同使用。

## 指令反馈

- 指令原文不保存为频道消息，也不向其他成员广播。
- 成功、参数错误、未知指令、目标不存在和权限不足均产生仅提交者可见的指令反馈。
- 指令反馈作为带“仅你可见”标识的本地项插入触发指令的聊天时间线。
- 反馈按文字频道保留在当前页面会话内；切换频道后返回仍可见，刷新页面后消失。
- 指令反馈不参与消息保留、未读数、通知音、消息操作菜单或频道历史。
- 网络连接级错误可以在本地反馈之外继续使用现有全局 Toast。
- 设置成功后不广播经验更新事件。其他客户端已经打开的个人信息卡片可以暂时显示旧值，关闭并重新打开后重新读取。

## 一致性与审计

- 服务端在一个 SQLite 事务中读取旧 XP、写入新 XP 并插入服务器审计记录。
- 并发设置与正常语音累计按数据库实际提交顺序生效；第一版不增加版本号或冲突确认。
- 每次成功的 `/xp set` 都写审计，包括设置为原值的情况。
- 审计记录包含操作者、目标成员、修改前 XP、修改后 XP 和时间，不保存原始指令文本。
- `/xp get`、参数错误、目标不存在和权限不足不写持久审计。
- 第一版不为 `/xp` 增加专项服务端限流。前端在请求处理中阻止重复提交；未来如有需要，应统一设计管理写操作限流。

## 模块设计

斜杠语法属于 Web 客户端交互。前端斜杠指令 module 在一个位置拥有命令目录、输入分类、解析、提示、成员补全、执行协调和本地反馈；`ChatPane` 只通过该 module 的小 interface 提交输入和读取建议，不自行拼接 XP 请求或维护另一份语法。

后端不增加接收任意字符串的 `/commands` 接口。领域接口保持与文本语法无关：

- `/xp get` 复用现有同服个人信息读取能力。
- `/xp set` 调用新的服务器成员语音经验设置接口；路由使用成员数字 ID，前端只在交互层展示 `@登录名`。
- HTTP handler 负责认证、当前服务器成员范围和角色层级校验。
- Store 操作拥有原子设置与审计事务，并返回服务端确认的修改前后 XP 与等级进度。
- 设置接口不触发 WebSocket 广播。

当前 Android 客户端复用同一套 Web 前端，因此首版只有一个斜杠语法实现。未来出现真正独立的第二客户端时，再重新评估是否需要服务端命令目录或共享协议。

## 验收范围

后端测试覆盖：

- 经验设置的范围校验、原值返回、绝对覆盖、设置为原值和审计内容。
- 设置与语音累计的事务顺序，不把经验设置误写入语音时长。
- 所有者、普通管理员、已加入的平台管理员和普通成员的权限矩阵。
- 活跃成员、封禁成员、已移出成员和跨服务器成员的目标范围。
- 设置成功不广播 WebSocket 事件。

前端测试覆盖：

- 普通消息、`/` 指令和 `//` 转义的输入分类。
- 大小写、空白、缺失参数、多余参数、成员目标与 XP 范围解析。
- 指令与活跃成员补全，以及鼠标、触摸和键盘操作。
- 文字禁言状态下仍可执行私有指令，但不能发送普通消息。
- 成功清空输入，失败保留输入；本地反馈仅存在于触发频道的当前页面会话。
- 普通成员不展示 `set` 建议，服务端拒绝手工构造的越权请求。

端到端测试至少验证普通成员查询、所有者设置、普通管理员目标限制、私有反馈不出现在第二客户端、刷新后反馈消失，以及设置后重新打开个人信息卡片读取新经验。

## 不在范围内

- 独立管理员控制台页或 Shell 替代品
- 平台账号、邀请码、服务器创建或删除等平台级指令
- `/xp add`、经验冻结、批量设置和撤销指令
- 命令专属权限 ACL
- 服务端通用命令解析器或命令元数据接口
- 命令历史、持久化指令反馈和专项限流
- 经验更新 WebSocket 广播
