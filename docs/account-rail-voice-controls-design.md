# 账户入口与语音控制区重构设计

## 背景

当前频道栏底部的用户控制区同时承载账号身份、语音状态、麦克风控制、耳机静音、背景音、用户设置和退出登录。`退出登录` 的图标与语音应用中常见的“断开通话”表达接近，容易让用户在没有阅读提示时误判操作含义；账号身份本身也不属于当前频道的信息层级。

移动端在不超过 760px 时完全隐藏服务器栏，只在频道抽屉中提供服务器下拉选择。用户需要先打开频道抽屉才能切换服务器，入口不持续可见，也与桌面端服务器图标的操作模型不同。

本次重构将账号入口移动到服务器栏底部，并把原用户控制区收敛为纯语音控制。移动端同时保留一条持续可见的服务器窄栏，以建立一致的服务器、账号与语音操作层级。

## 设计目标

- 将账号操作与语音操作分离，消除退出登录和断开语音的语义混淆。
- 在桌面端和移动端都让服务器切换与账号入口持续可见。
- 保留现有服务器操作菜单、频道抽屉和用户设置能力，不建立重复入口。
- 让语音连接区只表达连接状态和语音控制。
- 提供浏览器本地的 DTX 模式切换，不引入客户端音频门控。
- 保持键盘操作、焦点恢复、危险操作确认和窄屏安全区域适配。

## 非目标

- 不支持头像上传；头像继续由显示名称生成颜色和首字符。
- 不新增账户级未读红点，只保留绿色在线状态点。
- 不实现客户端 VAD 音频门控、灵敏度设置、实时阈值校准或按键说话。
- 不改变服务端账号、服务器成员关系或语音权限模型。
- 不改变应用背景音的采集、发布或控制能力。

## 信息架构

### 服务器栏

桌面端继续使用 72px 服务器栏。移动端在不超过 760px 时使用 56px 服务器栏，并永久占据视口左侧；聊天和临时抽屉只能使用其右侧的剩余宽度。

两端服务器栏使用相同顺序：

1. 产品标识。
2. 业务连接状态。
3. 平台管理入口（仅平台管理员）。
4. 独立滚动的服务器列表和创建服务器入口。
5. 与服务器列表分隔、固定在底部的当前用户头像。

服务器较多时只有中间列表滚动，顶部入口和底部头像始终可见。移动端按钮继续使用现有 46px 服务器图标尺寸，由 56px 栏宽提供两侧间距。底部需考虑 `safe-area-inset-bottom`。

头像只显示绿色在线状态点。头像按钮提供当前用户名称的可访问名称；桌面端可通过悬停提示识别账户入口。

### 账户菜单

单击头像后，从头像右侧向上打开账户菜单。菜单结构为：

- 只读用户摘要：头像、显示名称、用户名与在线状态。
- `用户设置`。
- 分隔线。
- 红色图标和文字的 `退出登录`。

点击 `用户设置` 时先关闭菜单，再打开现有用户设置面板。点击 `退出登录` 时先关闭菜单，再打开现有二次确认；用户仍在语音中时继续提示退出会断开当前语音连接。

菜单通过点击外部、`Escape` 或执行菜单项关闭。键盘支持方向键、`Home`、`End`、`Enter` 和空格。普通关闭后将焦点恢复到头像按钮；打开设置或退出确认时将焦点交给目标面板。

移动端点击头像时先关闭频道抽屉，再打开账户菜单，避免两个浮层重叠。设置、退出确认等模态界面继续覆盖整个视口。

## 移动端服务器与频道导航

移动端删除服务器标题中的下拉选择器，服务器切换统一通过持续可见的服务器栏完成。

- 点击其他已加入服务器：切换服务器并打开频道抽屉。
- 点击当前服务器：切换频道抽屉的展开或收起状态。
- 点击仅管理信息的服务器：保持现有行为，打开平台服务器管理。
- 聊天标题栏现有的频道按钮继续保留，只负责打开当前服务器的频道抽屉。

频道抽屉从 56px 服务器栏的右侧开始，宽度为 `min(300px, calc(100vw - 56px))`。频道遮罩只覆盖抽屉右侧的聊天区域，服务器栏在抽屉打开时保持可操作，允许连续切换服务器。

移动端频道标题继续保留当前服务器名称、服务器操作菜单和关闭按钮。服务器操作菜单仍作用于当前标题对应的服务器。

成员抽屉、设置面板和其他模态界面不属于服务器连续切换流程，可以继续覆盖服务器栏并阻止其交互。

## 纯语音控制区

头像、用户名称、用户设置和退出登录从 `UserControls` 移出。未加入语音时不显示底部语音连接区和工具栏；加入语音后显示两行结构：

1. 连接信息行：服务器、频道和连接/重连状态，只读展示。
2. 语音工具栏：左侧为传输模式按钮，右侧为语音操作按钮组。

右侧按钮组靠右排列，依次包含：

- 麦克风静音。
- 耳机静音。
- 应用背景音（仅能力和连接状态满足现有条件时显示）。
- 分隔线。
- 红色 `PhoneOff` 图标的断开语音。

断开语音保持单击立即执行，不增加确认弹窗。该操作可随时通过语音频道重新加入，且在位置、图标和交互上与头像菜单中的退出登录明确区分。连接信息行不再保留 `X` 断开按钮。

背景音控制面板继续锚定背景音按钮，并保持现有播放、暂停、停止、音量与错误反馈。

## DTX 模式

### 产品语义

工具栏左侧使用紧凑的“图标 + 当前模式文本”按钮，不使用只有图标的含糊切换：

- `语音感应`：麦克风发布参数 `dtx: true`。
- `持续传输`：麦克风发布参数 `dtx: false`。

这是两个平级传输模式，不是向用户暴露的布尔开关。两种模式的图标和文字统一使用白色，不用绿色区分 DTX 的开启与关闭；绿色继续保留给在线等具有明确正向状态含义的反馈。模式只通过当前文本和对应图标区分，不增加勾选、开关轨道或状态点。

按钮宽度随图标和当前文本自适应，横向内边距约为 `8px`，可点击高度约为 `44px`；可见交互背景在命中区内纵向收紧到约 `34px`，避免背景尺寸与紧凑文字失衡。右侧语音操作按钮组独立靠右，两个正常长度的模式文案互相切换时不得推动右侧按钮。静止状态无背景；支持精确悬停的设备和键盘聚焦使用相同的中性浅灰背景，按下时略深，切换中仅降低透明度并禁止重复点击。触摸设备不保留粘滞 hover 背景。

可见文本表示当前模式，tooltip 表示点击后的动作：当前为 `语音感应` 时提示“切换为持续传输”，当前为 `持续传输` 时提示“切换为语音感应”。默认使用 `语音感应`，与当前发布参数一致。选择通过 `localStorage` 在当前浏览器全局保存，对所有服务器和频道生效。

本按钮只控制 Opus DTX。它不承诺可调阈值的客户端语音门控；`语音感应` 是面向用户的简化表述。

### 状态切换

- 未加入语音时没有工具栏，保存的模式在下次加入时用于创建房间和发布麦克风。
- 麦克风正在发送时切换模式，重新应用麦克风发布参数；允许出现一次很短的音频中断。
- 麦克风静音、耳机静音或被管理员语音禁言时，只更新并保存选择，不临时启用麦克风；下次允许发布时应用新模式。
- 切换期间按钮显示加载状态并禁用重复操作。
- 在线应用失败时回滚到原模式和原存储值，保持语音连接，并在连接区域显示明确错误。
- 频道级码率或 RED 设置触发重新发布时，必须同时使用当前 DTX 模式，不能恢复为硬编码开启。

DTX 状态属于浏览器设备偏好，不写入账号资料或服务端数据库。

## 响应式与层级

- 大于 760px：72px 服务器栏、固定频道栏和现有成员栏规则保持不变。
- 不超过 760px：56px 服务器栏持续可见，聊天区从其右侧开始。
- 频道抽屉层级高于聊天与频道遮罩，但不覆盖服务器栏。
- 账户菜单层级高于普通抽屉；移动端打开前主动关闭频道抽屉。
- 模态面板和成员抽屉可以覆盖整个视口，并高于服务器栏与账户菜单。
- 极窄视口下，频道抽屉、账户菜单、语音工具栏和聊天内容不得产生横向溢出或文字覆盖。

## 可访问性

- 头像是原生按钮，具有用户账户的 `aria-label`、`aria-expanded` 和菜单关联。
- 账户浮层使用 `menu`/`menuitem` 语义，用户摘要不进入菜单项键盘循环。
- DTX 模式按钮通过可见文本表达当前模式，通过 tooltip 表达将要切换到的模式；不使用 `aria-pressed`，避免把平级模式误表达为布尔开关。
- tooltip 在桌面悬停和键盘聚焦时可见。按钮的无障碍名称同时说明当前模式和切换目标，使移动端触摸用户不依赖 hover 也能理解操作。
- 图标按钮继续提供明确的 `title`；断开语音的名称必须是“断开语音”，不能只写“退出”或“关闭”。
- 加载和失败状态通过禁用状态与可见文本反馈，不仅依赖颜色。
- 危险色需要在明暗主题中保持足够对比度。

## 验证范围

- 桌面和移动端头像位置、在线点、菜单定位及服务器列表滚动。
- 账户菜单的键盘导航、外部关闭、焦点恢复、设置入口和退出确认。
- 移动端服务器切换、当前服务器抽屉切换、频道按钮、遮罩范围和连续切换。
- 320px 等窄视口与安全区域下的固定栏、抽屉和语音工具栏布局。
- 未加入语音时不显示工具栏；加入后连接信息与全部可用控制正确显示。
- 断开语音单击执行，退出登录仍需确认，两者的可访问名称和图标不混淆。
- DTX 默认值、持久化、跨服务器复用、加入时发布参数、在线切换、静音延迟应用、失败回滚。
- DTX 与频道码率/RED 更新、耳机静音、管理员语音禁言和应用背景音的组合状态。
- 两种模式使用相同的中性前景色；hover 背景紧凑包裹内容，按钮满足触控高度，模式切换不改变右侧语音操作按钮的位置。
- tooltip、键盘焦点和移动端无障碍名称都能区分当前模式与切换目标。
