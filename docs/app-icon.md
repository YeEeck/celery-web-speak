# 应用图标规范

应用图标的 SVG 真源存放在 `web/public/favicon.svg`，遵循以下约定：

- 使用正方形 `viewBox`，图标主体铺满画布，不保留参考图四周的浅灰留白。
- 背景为黑色标准圆角矩形，前景为绿色的芹菜与对话气泡组合图形。
- 右下角的白色闪光属于参考图装饰，不纳入应用图标。
- 所有图形均使用 SVG 路径绘制，不嵌入位图，确保在不同尺寸下清晰显示。
- SVG 默认提供可访问名称，并使用固定配色，便于浏览器和桌面客户端直接引用。
- 页面入口通过 `/favicon.svg` 引用图标，Vite 构建时将其复制到输出目录根级。

## 尺寸适配

- SVG 保持 `512 x 512` 的方形 `viewBox`，浏览器页签和 Web UI 共用同一个真源。
- 正式检查 `16`、`24`、`32`、`46`、`58`、`64` 和 `512` 像素渲染；当前轮廓在这些尺寸下无需维护简化变体。
- HTML 的 SVG favicon 声明使用 `sizes="any"`，由浏览器按目标尺寸栅格化。
- Electron 打包图标从 SVG 真源生成，不允许从小尺寸 PNG 继续放大。

## 使用位置

- 浏览器页签使用 `/favicon.svg`。
- Web 启动画面、错误画面、登录页和服务器栏使用 `/favicon.svg`，不再显示字母占位符。
- Electron 窗口图标与安装包图标需要同时配置；Windows 使用包含多尺寸图层的 ICO，Linux 使用至少 `512 x 512` 的 PNG。

当前仓库尚未包含 Electron 工程或打包配置。Electron 客户端接入时必须同时配置 `BrowserWindow` 图标和打包工具图标，不能仅依赖远程页面的 favicon。
