# Celery Web Speak 产品规格

## 产品目标

Celery Web Speak 是一个面向小型固定群体的单频道在线语音与文字聊天工具。界面参考 Discord，优先保证语音连接稳定性与操作清晰度，不实现多房间、视频、屏幕共享和文件传输。

目标环境：

- 日常同时在线不超过 5 人，设计上支持 10 人
- 公网单机部署，Linux amd64，Docker Compose
- 桌面 Chrome、桌面 Edge 和 Android Chrome
- Nginx 负责 HTTPS/WSS 入口与证书管理

## 用户与权限

系统包含三级角色：

| 能力 | 普通成员 | 频道管理员 | 服务器管理员 |
| --- | --- | --- | --- |
| 语音与文字聊天 | 是 | 是 | 是 |
| 管理频道音质与消息保留数量 | 否 | 是 | 是 |
| 分别执行语音禁言、文字禁言 | 否 | 是 | 是 |
| 踢出并设置临时封禁 | 否 | 是 | 是 |
| 删除消息 | 否 | 是 | 是 |
| 创建邀请码、预建账号、重置密码 | 否 | 否 | 是 |
| 永久封禁账号 | 否 | 否 | 是 |
| 任命频道管理员 | 否 | 否 | 是 |
| 任命服务器管理员 | 否 | 否 | 是 |

- 首个服务器管理员由启动环境变量初始化。
- 登录名全局唯一且不可修改；显示名称可由用户修改。
- 用户可修改自己的密码，管理员可重置密码；不提供邮件找回。
- 登录会话有效期为 30 天。
- 注册必须使用具有有效期和最大使用次数的邀请码；服务器管理员也可直接创建账号。

## 语音

- 用户点击唯一的语音频道后连接，不自动连接。
- 使用 LiveKit SFU 集中转发，允许所有用户同时发言。
- 使用 Opus 单声道音频，开启浏览器回声消除、噪声抑制和自动增益控制。
- 频道发送码率由管理员统一设置：32-128 kbps，步长 8 kbps，默认 64 kbps。
- 设置变更立即持久化，并通知在线用户重新发布音轨。
- 支持麦克风静音、耳机静音、输入设备选择、输出设备选择。
- 支持在 0%-300% 范围内调节本地麦克风增益和全局扬声器音量；默认均为 100%。
- 支持在 0%-300% 范围内按用户调节本地播放音量；未设置过的用户默认音量为 100%。
- 麦克风、扬声器和按用户音量设置保存在浏览器 localStorage。全局扬声器与按用户音量叠加后的实际播放增益最高限制为 300%。
- 显示当前发言者、连接状态和网络质量。
- 网络中断后自动重连，并允许用户主动断开。
- 管理员语音禁言与文字禁言是两个独立状态。

## 文字聊天

- 未连接语音时仍可查看和发送消息。
- 消息以纯文本发送，单条最多 2,000 个字符，并进行轻量频率限制。
- 不支持编辑、回复、表情回应、Markdown、链接预览、图片、附件或语音消息。
- 默认保留全频道最近 500 条消息；管理员可在 100-5,000 范围内调整。
- 超出保留数量的旧消息自动从 SQLite 删除。

## 管理行为

- 踢出操作同时设置禁止重新进入的截止时间。
- 提供 5 分钟、30 分钟、1 小时、24 小时预设和自定义时间。
- 永久封禁为服务器管理员的独立操作。
- 频道管理员不能创建、修改或撤销任何管理员角色。

## 明确不做

- 多服务器、多频道或私聊
- 视频、屏幕共享、录音
- 图片、文件和语音消息
- iOS/Safari 专项支持
- 移动端锁屏或切后台持续通话保证
- 邮件、短信和第三方账号登录
- 严格企业网络的 TURN/TLS 443 穿透
- 证书申请和续期管理

## 验收标准

5 个桌面或 Android Chrome 客户端连续通话 2 小时，期间完成断网重连、麦克风切换、静音、耳机静音、按用户音量调整、文字聊天和管理操作，服务无崩溃。生产服务器通过预构建镜像执行 `docker compose up -d`，不在服务器现场编译应用或 LiveKit。
