# Celery Web Speak 产品规格

> 当前实现基线：受控多服务器。本文与《受控多服务器设计》共同描述当前产品边界；未列出的扩展能力不视为已支持。

## 产品目标

Celery Web Speak 是一个允许同一平台部署承载多个小型固定群体的公开多频道在线语音与文字聊天工具。逻辑服务器隔离成员、频道、消息、在线和语音状态；文字频道与语音频道是完全独立的实体。

目标环境：

- 日常同时在线不超过 5 人，设计上支持 10 人
- 公网单机部署，Linux amd64，Docker Compose
- 桌面 Chrome、桌面 Edge 和 Android Chrome
- 默认由 Compose 内的 Caddy Gateway 负责 HTTPS/WSS 入口与公网 IP 证书管理，也可禁用 Gateway 后接入自管反向代理

## 用户与权限

平台账号、邀请码和登录会话全局有效。只有平台管理员可以创建或删除逻辑服务器、指定和转让所有者；平台邀请码只创建账号，不自动加入服务器。所有者或服务器管理员通过完整登录名添加已有账号，普通用户只看到自己已加入的服务器。平台管理员可以看到全部服务器元数据，但必须显式加入后才能读取成员、频道、消息、在线或语音状态。

每个服务器有所有者、管理员和成员三种有效角色。所有者可任命管理员，管理员只能管理普通成员；禁言和封禁均以服务器为范围。频道仍对所属服务器内全部有效成员公开，当前版本不实现私密频道。

权限分为平台和服务器两层：

| 能力 | 平台管理员 | 服务器所有者 | 服务器管理员 | 普通成员 |
| --- | --- | --- | --- | --- |
| 创建、删除服务器和转让所有权 | 是 | 否 | 否 | 否 |
| 查看未加入服务器的元数据 | 是 | 否 | 否 | 否 |
| 读取服务器内容 | 显式加入后 | 是 | 是 | 是 |
| 管理平台账号和邀请码 | 是 | 否 | 否 | 否 |
| 重命名服务器 | 是 | 是 | 否 | 否 |
| 创建、设置和删除频道 | 加入后 | 是 | 是 | 否 |
| 添加、移出和审核普通成员 | 加入后 | 是 | 是 | 否 |
| 任命或撤销服务器管理员 | 加入后 | 是 | 否 | 否 |

- 首个平台管理员由启动环境变量初始化；平台管理界面可继续任命普通账号，并保证至少保留一名平台管理员。
- 所有频道只对所属服务器的有效成员可见；所有者和服务器管理员对本服务器全部公开频道拥有相同频道管理权限，不提供频道成员、私密频道或频道级角色。
- 语音禁言、文字禁言、临时封禁和永久封禁均为服务器级状态，不影响同一账号访问其他服务器。
- 登录名全局唯一且不可修改；显示名称可由用户修改。
- 登录名为 3-32 位字母、数字、下划线或连字符；显示名称为 1-32 个字符；密码为 10-128 个字符。
- 用户可修改自己的密码，平台管理员可重置密码；不提供邮件找回。
- 登录会话有效期为 30 天。
- 注册必须使用具有有效期和最大使用次数的平台邀请码；平台管理员也可直接创建账号。注册不会自动加入任何服务器。
- 头像由显示名称稳定生成纯色底和首字符，不上传或保存头像文件。
- 平台管理员重置密码后，目标账号的现有会话全部失效，并立即断开业务 WebSocket 和语音连接。
- 平台管理员可以不可恢复地删除账号，但不能删除自己或系统中的最后一名平台管理员；目标拥有服务器时必须先转让所有权或删除服务器。
- 删除账号后立即撤销其全部会话并断开业务 WebSocket 和 LiveKit 连接，账号从成员、在线和管理列表中消失。已永久或临时封禁的账号仍可删除。
- 删除账号保留历史文字消息、其创建的邀请码和审计关联，但匿名化原登录名、显示名称和认证信息；历史消息发送者显示为“已删除用户”。原登录名立即释放，之后创建的同名账号使用新的用户 ID，与旧账号无关。
- 删除不提供恢复入口。确认弹窗必须说明影响，并要求准确输入目标登录名；成功后通过实时事件从所有在线客户端移除该成员。
- 当前用户头像固定在服务器栏底部，只显示绿色在线状态点。点击头像打开账户菜单，菜单顶部只读显示用户摘要，操作项为“用户设置”和红色的“退出登录”；账号操作不在频道栏底部重复出现。
- 选择“退出登录”后打开应用内确认弹窗。弹窗提供“取消”和红色“退出”按钮；连接语音时额外说明退出会断开当前语音。弹窗默认聚焦“取消”，支持点击外部、按 Escape 或点击“取消”关闭，关闭后将焦点还给头像按钮；确认期间禁用重复操作并显示处理状态。

### 邀请码管理

- 新生成的邀请码在平台管理控制台中与使用次数、到期时间、创建时间和状态显示在同一条记录内，并允许平台管理员再次复制。升级前只保存哈希的旧邀请码标记为“原码不可恢复”，但仍可查看状态、撤销或删除。
- 邀请码状态分为有效、已用完、已过期和已撤销。手动撤销优先显示为已撤销；有效邀请码排在其他状态之前，并按到期时间从近到远排列，其他邀请码按创建时间从新到旧排列。
- 邀请码列表由服务端排序和分页，每页最多返回 30 条。管理控制台通过“加载更多”继续读取，接口只返回是否还有下一页，不统计或一次读取全部记录。
- 撤销操作保持记录但立即禁止继续注册；永久删除会移除记录并立即失效。两种操作均需二次确认并写入审计日志，重复撤销保持幂等，不存在的邀请码返回未找到。
- 不支持恢复、修改次数或延长有效期；需要变更时撤销或删除旧邀请码并创建新邀请码。

## 界面与响应式布局

- 宽度大于 1,140px 时，成员列表作为右侧栏显示，右上角成员按钮可折叠或展开该侧栏，聊天区域随之占用释放的空间。
- 宽度为 761-1,140px 时保留左侧频道栏，成员按钮从右侧打开覆盖式成员抽屉。
- 非移动布局的服务器栏固定为 72px，频道栏固定为 300px，右侧成员栏固定为 264px。服务器列表独立滚动，产品标识、连接状态、平台管理入口和底部用户头像不随列表滚动。
- 频道栏底部只在已加入语音时显示连接信息和纯语音工具栏。连接信息行只读展示服务器、频道和连接状态；工具栏左侧显示 DTX 模式，右侧靠右排列麦克风、耳机静音、可用时的应用背景音和红色 `PhoneOff` 断开语音按钮。断开语音单击立即执行，不与退出登录共用入口或图标。
- 管理控制台、平台服务器管理和离开服务器统一收纳在服务器操作菜单，不在频道列表中重复显示。当前服务器通过标题旁的竖向三点按钮打开菜单；桌面端也可右键服务器栏中的任意服务器，菜单操作始终作用于触发入口对应的服务器。
- 频道栏中同类型的相邻频道项保留 4px 垂直间距；语音频道展开的成员区属于对应频道项，整体与相邻语音频道保持该间距。
- 宽度不超过 760px 时，左侧持续显示 56px 服务器栏，聊天区使用剩余宽度；频道栏和成员列表仍分别通过左右抽屉显示。频道抽屉从服务器栏右侧展开，宽度为 `min(300px, calc(100vw - 56px))`，遮罩不覆盖服务器栏。点击其他服务器会切换服务器并打开频道抽屉，点击当前服务器切换抽屉状态；不再提供服务器下拉选择器。打开头像账户菜单前关闭频道抽屉，改变布局断点时关闭临时抽屉和账户菜单。
- 管理控制台的最外层外框由标题栏、页签栏、内容区和底部状态栏共享，不由当前页签的内容高度撑开。视口至少为 1028 × 868px 时，外框严格保持 980 × 820px，不按视口比例连续缩放；任一方向无法保留 24px 边距时，整个控制台直接切换为全屏模式。切换“频道”、“成员”和“账号与邀请”时外框尺寸不得变化。
- 管理控制台的标题栏、页签栏和底部状态栏始终固定，“频道”和“账号与邀请”的中间内容区在溢出时滚动。“成员”页的成员列表与管理详情占满中间区域并分别滚动，任一侧滚动到边界时不得带动另一侧。
- 管理控制台在不超过 760px 的窄屏上由共享外框占满动态视口高度。“成员”页改为上下分区：顶部成员列表保持约 150px 高，下方管理详情占用剩余空间，两者分别滚动。
- 切换管理对象时，右侧或下方的管理详情回到顶部，成员列表保留原滚动位置；滚动条仅在内容溢出时显示。
- 用户音频设置外框由固定标题栏、页签栏、内容滚动区和固定底栏组成；管理控制台保持对应的四段式布局。紧凑视口下页签栏不得收缩或与内容区重叠，内容溢出仅由中间内容区滚动，不得遮挡保存或关闭操作。
- 用户设置中的相邻分区使用分隔线区分；除首个分区外，分区标题与其上方分隔线之间保留 22px 间距，避免标题、图标与分隔线贴合。

## 在线状态

- 在线状态只表示账号至少有一个已连接的业务页面，与正在查看的文字频道及是否加入语音频道无关。
- 同一账号允许同时打开多个标签页、浏览器或设备；任一业务 WebSocket 仍有效时，该账号保持在线，最后一个连接关闭后才转为离线。
- 页面正常关闭时立即更新在线状态。强制结束浏览器、断网或休眠等异常中断以最后一次有效 WebSocket 心跳为准，最多保留 15 秒在线租约；租约内恢复连接不产生离线再上线的闪烁。
- 在线状态变更通过业务 WebSocket 实时广播。服务端每 15 秒无条件补发一次完整在线账号快照，修复单次事件未送达造成的客户端状态漂移。
- 在线成员显示网页端、桌面端或安卓端类型徽章；同一账号多端在线时按桌面端、安卓端、网页端的优先级显示一个徽章。客户端类型由客户端自报，只用于界面提示，不参与权限或功能判断。
- 在线快照使用独立的最新值缓冲，不因普通业务事件队列已满而丢弃；同一客户端尚未发送的旧快照可由更新的完整快照替代。
- 业务 WebSocket 负责实时增量事件；每次连接建立或重连后，前端通过 HTTP 重新读取权威频道、成员、已读与当前文字频道消息快照。普通事件队列溢出时服务端关闭该连接，由相同恢复流程纠正状态。

## 语音

- 用户点击任一语音频道后连接，不自动连接；正在查看的文字频道与连接的语音频道彼此独立。
- 同一账号在所有标签页和设备上只能连接一个语音频道。新的连接会断开该账号此前的语音连接。
- 每次签发语音加入令牌时生成递增代次；令牌有效期内只接受该账号最新签发代次对应的目标频道，旧标签页或设备延迟使用旧令牌时由服务端移除。
- 频道栏实时显示每个语音频道内的成员；LiveKit Webhook 提供实时变更，服务端在启动、业务连接建立及默认每 15 秒的后台校准中同步全量语音占用状态。
- 后台校准失败时保留最后一次有效快照并继续重试；只有状态实际变化时才向客户端广播。校准发现同一账号残留在多个房间时保留最新有效令牌对应的连接并移除旧连接，同时删除数据库中已不存在频道对应的孤儿房间。
- 使用 LiveKit SFU 集中转发，允许所有用户同时发言。
- 使用 Opus 单声道音频，开启浏览器回声消除、噪声抑制和自动增益控制。
- 语音音轨默认开启 DTX、禁用强制立体声；用户可在“语音感应”（DTX 开启）和“持续传输”（DTX 关闭）间切换。模式作为当前浏览器的全局设备偏好保存，对所有服务器与频道生效；本功能不实现客户端音频门控或可调触发阈值。
- 麦克风正在发送时切换 DTX 会重新发布音轨，失败时恢复旧模式和存储值并显示错误；麦克风静音、耳机静音或管理员语音禁言时只保存选择，下次允许发布时应用。每个频道可独立开关语音 RED，默认开启；频道码率或 RED 变化引发重新发布时必须保留当前 DTX 模式。
- 每个语音频道独立配置发送码率：32-128 kbps，步长 8 kbps，默认 64 kbps。
- 设置变更立即持久化，并仅通知该语音频道内的在线用户重新发布受影响的音轨。
- 支持麦克风静音、耳机静音、输入设备选择、输出设备选择。语音频道成员列表对自己和其他参与者显示麦克风静音与耳机静音图标，正常状态不占用额外图标空间。
- 开启耳机静音时同时关闭麦克风，并记住开启前的麦克风状态；关闭耳机静音时，仅当麦克风是由耳机静音联动关闭时才自动恢复。耳机静音期间不能单独取消麦克风静音，管理员语音禁言始终优先且不能被本地操作解除。
- 本地麦克风与耳机静音状态在 LiveKit 自动重连时保留，在主动离开、退出登录或刷新页面后重置。耳机静音状态只属于当前语音会话，不写入账号资料或浏览器存储。
- 本地静音操作优先于状态同步：向其他参与者同步耳机静音失败时保持本地麦克风与耳机静音，显示同步失败提示，并在连接恢复后重试。
- 本地媒体轨道切换失败时不得发布未实际完成的耳机静音状态；客户端恢复切换前的耳机与提示音状态，并按麦克风轨道的实际状态刷新界面。
- 支持在 0%-300% 范围内调节本地麦克风增益和全局扬声器音量；默认均为 100%。
- 支持在 0%-300% 范围内按用户分别调节远端麦克风和背景音的本地播放音量；两类音量相互独立，未设置过的用户均默认 100%。
- 远端用户存在背景音轨时显示独立背景音音量控件，播放中和暂停时均可调节；停止共享、轨道取消发布或用户离开后隐藏控件，但保留该用户的设置。
- 麦克风、扬声器、按用户麦克风音量和按用户背景音音量设置保存在浏览器 localStorage。全局扬声器与各音轨按用户音量叠加后的实际播放增益分别最高限制为 300%。
- 显示当前发言者、连接状态和网络质量。
- 语音频道成员依次按服务器所有者、服务器管理员、普通成员分组，同级成员按本次进入频道的服务端时间先后排列；发言状态、静音状态和网络质量变化不得改变顺序。
- LiveKit 自动重连保留原进入顺序；用户主动离开后再次进入视为新加入。角色变更立即更新排序，时间相同或缺失时按用户数字 ID 排列，本地用户不固定置顶。
- 网络中断后自动重连，并允许用户主动断开。
- 管理员语音禁言与文字禁言是两个独立状态。
- 每个账号使用固定的 LiveKit identity；服务端在多个 LiveKit 房间间统一执行单连接约束。

## 文字聊天

- 用户一次查看一个文字频道，可以在保持语音连接的同时自由切换文字频道。
- 未连接语音时仍可查看和发送消息。
- 消息以纯文本发送，单条最多 2,000 个字符；同一用户最多在 10 秒内发送 8 条消息。
- 不支持编辑、回复、表情回应、Markdown、链接预览、图片、附件或语音消息。
- 每个文字频道默认保留最近 500 条消息；管理员可分别在 100-5,000 范围内调整。
- 超出对应频道保留数量的旧消息自动从 SQLite 删除，不影响其他频道。
- 首次进入时只加载最新 50 条消息，历史消息按 50 条一页使用消息 ID 游标主动向前加载；接口明确返回是否还有更早消息，到达频道起点后显示结束状态。
- 前端使用支持不等高内容的虚拟列表，只渲染视口附近的消息，并按管理员设置的保留数量裁剪内存中的最旧记录。
- 每个文字频道独立保存消息分页状态、草稿、滚动位置和未读数量。草稿与滚动位置保存在当前浏览器，最后已读消息由服务端保存并跨设备同步。
- 只有当前文字频道处于激活状态且滚动到底部时才标记已读。切换到频道不会自动清除未读；加载更早消息后保持当前阅读位置。
- 用户离开底部后显示“回到最新消息”，期间收到新消息时累计未读数量，点击并到达底部后清零。
- 实时未读数量不超过对应频道当前的消息保留数量；服务端淘汰旧消息或管理员降低保留数量后，客户端按权威快照与保留上限校准。
- 消息列表底部与文字输入框之间保留至少 16px 的可见间距，最新消息不得紧贴或遮挡输入区域。
- 暂不提供自动连续加载历史、消息搜索、日期跳转和页码导航。

## 操作提示音

- 内置相互可区分的加入语音、退出语音和新文字消息提示音，不依赖外部音频地址，也不仿制第三方产品音效。
- 用户自己成功加入语音频道时播放一次加入音效；其他用户在初始成员同步完成后加入或退出时分别播放对应音效。自己退出时不播放退出音效。
- 初次加入时不为频道内已有成员逐个播放音效；网络重连和成员列表重新同步不得产生加入或退出提示。
- 当前正在查看的文字频道收到其他用户的新消息时播放消息音效，自己发送的消息不播放。未进入的文字频道只增加未读数量，不播放提示音。
- 用户设置提供提示音总开关、0%-100% 的提示音音量，以及加入、退出、消息三个独立开关；默认总开关和三个独立开关均开启，默认音量为 60%，设置保存在浏览器 localStorage。
- 耳机静音同时静音所有操作提示音。提示音优先跟随用户选择的输出设备，浏览器不支持指定输出设备时回退到系统默认设备。
- 同类提示音设置 300ms 最小播放间隔，避免短时间内的批量事件形成叠音；不同类型提示音仍保持可区分。
- 提示音遵循浏览器自动播放限制。用户首次交互前无法播放的事件直接跳过，不延迟补播；Android 后台播放只在浏览器允许范围内尽力执行，不作可靠性保证。

## 管理行为

- 服务器所有者和服务器管理员可以创建、重命名和永久删除公开频道。文字频道和语音频道分别最多 50 个，同类型名称不区分大小写且必须唯一。
- 频道按创建顺序排列，不提供分类、拖拽排序、分享 URL 或频道类型转换。
- 系统始终至少保留一个文字频道和一个语音频道，最后一个同类型频道不能删除。
- 删除文字频道会永久删除其中消息、已读位置和本地频道状态；删除语音频道会立即断开其中参与者。删除均需二次确认并写入审计日志。
- 移出成员会删除服务器成员关系但保留历史消息，之后可以由管理员重新添加；成员和管理员也可以主动离开，所有者必须先转让所有权。主动离开前使用应用内对话框明确说明成员身份会被移除、需要管理员重新添加且历史消息不会删除；离开非当前服务器不改变当前页面，离开当前服务器则选择剩余的第一个服务器。
- 临时封禁提供 5 分钟、30 分钟、1 小时和 24 小时预设；永久封禁保留成员关系，防止封禁期间重新添加。
- 服务器管理员只能管理普通成员；所有者可以管理服务器管理员，平台管理员显式加入后按权限矩阵管理成员。
- 临时或永久封禁只撤销目标服务器的 HTTP、WebSocket 和 LiveKit 访问，不影响目标账号的全局会话或其他服务器。解除封禁后恢复该服务器成员访问。
- 平台停用、重置密码和账号删除属于全局操作，会撤销目标全部会话并断开全部业务 WebSocket 和 LiveKit 连接。
- 解除临时封禁不改变各文字频道的最后已读位置。账号删除在单个事务中完成删除标记、身份匿名化、会话、临时封禁与频道已读状态清理和审计记录；审计详情保留目标用户 ID、删除前登录名及删除时间。重复删除按账号不存在处理。

## 明确不做

- 私密频道、频道成员关系或私聊
- 频道分类、手动排序、频道类型转换和频道分享 URL
- 视频、屏幕共享、录音
- 图片、文件和语音消息
- iOS/Safari 专项支持
- 移动端锁屏或切后台持续通话保证
- 邮件、短信和第三方账号登录
- 严格企业网络的 TURN/TLS 443 穿透

## 验收标准

- 自动化检查包含 Go 单元与接口测试、Vue 类型检查和生产构建，以及桌面 Chromium 与 Android Chromium 端到端测试。
- 多频道自动化检查覆盖文字消息与保留策略隔离、跨设备已读、频道删除、语音房间隔离、语音成员总览和同账号语音连接抢占。
- 在线状态自动化检查覆盖浏览器正常关闭、强制结束进程、断网后 15 秒内恢复、超过租约离线、同账号多连接以及周期完整快照纠偏。
- 完整 Compose 环境下的 LiveKit 双客户端测试覆盖远端音轨订阅、稳定成员排序、按用户独立麦克风与背景音音量、自己与他人加入提示及他人退出提示。
- 人工稳定性验收使用 5 个桌面或 Android Chrome 客户端连续通话 2 小时，期间完成断网重连、麦克风切换、静音、耳机静音、按用户音量调整、文字聊天和管理操作，服务无崩溃。
- 生产服务器通过预构建镜像执行 `docker compose up -d`，不在服务器现场编译应用或 LiveKit。
