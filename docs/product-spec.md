# Celery Web Speak 产品规格

## 产品目标

Celery Web Speak 是一个面向小型固定群体的单频道在线语音与文字聊天工具。界面参考 Discord，优先保证语音连接稳定性与操作清晰度，不实现多房间、视频、屏幕共享和文件传输。

目标环境：

- 日常同时在线不超过 5 人，设计上支持 10 人
- 公网单机部署，Linux amd64，Docker Compose
- 桌面 Chrome、桌面 Edge 和 Android Chrome
- Nginx 负责 HTTPS/WSS 入口与证书管理

## 用户与权限

系统包含三级角色：

| 能力 | 普通成员 | 频道管理员 | 服务器管理员 |
| --- | --- | --- | --- |
| 语音与文字聊天 | 是 | 是 | 是 |
| 管理频道音质与消息保留数量 | 否 | 是 | 是 |
| 分别执行语音禁言、文字禁言 | 否 | 是 | 是 |
| 踢出并设置临时封禁 | 否 | 是 | 是 |
| 删除消息 | 否 | 是 | 是 |
| 创建、撤销和删除邀请码，预建账号、重置密码 | 否 | 否 | 是 |
| 永久封禁账号 | 否 | 否 | 是 |
| 任命频道管理员 | 否 | 否 | 是 |
| 任命服务器管理员 | 否 | 否 | 是 |

- 首个服务器管理员由启动环境变量初始化。
- 登录名全局唯一且不可修改；显示名称可由用户修改。
- 用户可修改自己的密码，管理员可重置密码；不提供邮件找回。
- 登录会话有效期为 30 天。
- 注册必须使用具有有效期和最大使用次数的邀请码；服务器管理员也可直接创建账号。

### 邀请码管理

- 新生成的邀请码在管理控制台中与使用次数、到期时间、创建时间和状态显示在同一条记录内，并允许服务器管理员再次复制。升级前只保存哈希的旧邀请码标记为“原码不可恢复”，但仍可查看状态、撤销或删除。
- 邀请码状态分为有效、已用完、已过期和已撤销。手动撤销优先显示为已撤销；有效邀请码排在其他状态之前，并按到期时间从近到远排列，其他邀请码按创建时间从新到旧排列。
- 邀请码列表由服务端排序和分页，每页最多返回 30 条。管理控制台通过“加载更多”继续读取，接口只返回是否还有下一页，不统计或一次读取全部记录。
- 撤销操作保持记录但立即禁止继续注册；永久删除会移除记录并立即失效。两种操作均需二次确认并写入审计日志，重复撤销保持幂等，不存在的邀请码返回未找到。
- 不支持恢复、修改次数或延长有效期；需要变更时撤销或删除旧邀请码并创建新邀请码。

## 界面与响应式布局

- 宽度大于 1,100px 时，成员列表作为右侧栏显示，右上角成员按钮可折叠或展开该侧栏，聊天区域随之占用释放的空间。
- 宽度为 761-1,100px 时保留左侧频道栏，成员按钮从右侧打开覆盖式成员抽屉。
- 宽度不超过 760px 时，频道栏和成员列表分别通过左右抽屉显示；改变布局断点时关闭已打开的临时抽屉。
- 管理控制台的最外层外框由标题栏、页签栏、内容区和底部状态栏共享，不由当前页签的内容高度撑开。桌面端外框使用稳定的 980 × 820px 上限，视口不足时在四周保留 24px 后自适应缩小；切换“频道”、“成员”和“账号与邀请”时外框尺寸不得变化。
- 管理控制台的标题栏、页签栏和底部状态栏始终固定，“频道”和“账号与邀请”的中间内容区在溢出时滚动。“成员”页的成员列表与管理详情占满中间区域并分别滚动，任一侧滚动到边界时不得带动另一侧。
- 管理控制台在不超过 760px 的窄屏上由共享外框占满动态视口高度。“成员”页改为上下分区：顶部成员列表保持约 150px 高，下方管理详情占用剩余空间，两者分别滚动。
- 切换管理对象时，右侧或下方的管理详情回到顶部，成员列表保留原滚动位置；滚动条仅在内容溢出时显示。

## 语音

- 用户点击唯一的语音频道后连接，不自动连接。
- 使用 LiveKit SFU 集中转发，允许所有用户同时发言。
- 使用 Opus 单声道音频，开启浏览器回声消除、噪声抑制和自动增益控制。
- 频道发送码率由管理员统一设置：32-128 kbps，步长 8 kbps，默认 64 kbps。
- 设置变更立即持久化，并通知在线用户重新发布音轨。
- 支持麦克风静音、耳机静音、输入设备选择、输出设备选择。
- 支持在 0%-300% 范围内调节本地麦克风增益和全局扬声器音量；默认均为 100%。
- 支持在 0%-300% 范围内按用户调节本地播放音量；未设置过的用户默认音量为 100%。
- 麦克风、扬声器和按用户音量设置保存在浏览器 localStorage。全局扬声器与按用户音量叠加后的实际播放增益最高限制为 300%。
- 显示当前发言者、连接状态和网络质量。
- 语音频道成员依次按服务器管理员、频道管理员、普通成员分组，同级成员按本次进入频道的服务端时间先后排列；发言状态、静音状态和网络质量变化不得改变顺序。
- LiveKit 自动重连保留原进入顺序；用户主动离开后再次进入视为新加入。角色变更立即更新排序，时间相同或缺失时按用户数字 ID 排列，本地用户不固定置顶。
- 网络中断后自动重连，并允许用户主动断开。
- 管理员语音禁言与文字禁言是两个独立状态。

## 文字聊天

- 未连接语音时仍可查看和发送消息。
- 消息以纯文本发送，单条最多 2,000 个字符，并进行轻量频率限制。
- 不支持编辑、回复、表情回应、Markdown、链接预览、图片、附件或语音消息。
- 默认保留全频道最近 500 条消息；管理员可在 100-5,000 范围内调整。
- 超出保留数量的旧消息自动从 SQLite 删除。
- 首次进入时只加载最新 50 条消息，历史消息按 50 条一页使用消息 ID 游标主动向前加载；接口明确返回是否还有更早消息，到达频道起点后显示结束状态。
- 前端使用支持不等高内容的虚拟列表，只渲染视口附近的消息，并按管理员设置的保留数量裁剪内存中的最旧记录。
- 加载更早消息后保持当前阅读位置；用户离开底部后显示“回到最新消息”，期间收到新消息时累计未读数量，点击后回到底部并清零。
- 暂不提供自动连续加载历史、消息搜索、日期跳转和页码导航。

## 管理行为

- 踢出操作同时设置禁止重新进入的截止时间。
- 提供 5 分钟、30 分钟、1 小时、24 小时预设和自定义时间。
- 永久封禁为服务器管理员的独立操作。
- 频道管理员不能创建、修改或撤销任何管理员角色。

## 明确不做

- 多服务器、多频道或私聊
- 视频、屏幕共享、录音
- 图片、文件和语音消息
- iOS/Safari 专项支持
- 移动端锁屏或切后台持续通话保证
- 邮件、短信和第三方账号登录
- 严格企业网络的 TURN/TLS 443 穿透
- 证书申请和续期管理

## 验收标准

5 个桌面或 Android Chrome 客户端连续通话 2 小时，期间完成断网重连、麦克风切换、静音、耳机静音、按用户音量调整、文字聊天和管理操作，服务无崩溃。生产服务器通过预构建镜像执行 `docker compose up -d`，不在服务器现场编译应用或 LiveKit。
