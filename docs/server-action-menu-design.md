# 服务器操作菜单设计

## 背景

频道栏当前直接展示“管理控制台”和“离开服务器”两个服务器级操作。“离开服务器”紧邻频道列表，容易被理解为离开语音频道、退出登录或断开部署服务器；同时，它实际会移除当前账号的服务器成员身份，之后只能由服务器管理员重新添加，操作后果比现有入口表达得更重。

本次改动只调整服务器级操作的入口、表达和确认流程，不重命名产品中的“服务器”概念，也不改变后端成员关系语义。

## 设计目标

- 将服务器级操作从频道内容中移出，建立统一的服务器操作菜单。
- 保留“离开服务器”的自然文案，通过上下文、危险色和确认说明消除歧义。
- 允许用户直接操作左侧栏中的非当前服务器，同时始终明确操作目标。
- 桌面端和移动端均提供可发现、可访问的入口。
- 不改变服务器所有者、管理员、平台管理员和普通成员的现有权限边界。

## 入口与交互

### 当前服务器标题

当前服务器名称旁增加竖向三点图标按钮，按钮的可访问名称为“服务器操作”。点击后在按钮下方打开当前服务器的操作菜单。

移动端继续通过频道抽屉展示服务器标题和操作按钮。已有的频道抽屉入口仍使用三条杠菜单图标，服务器操作使用竖向三点图标，避免两个入口含义相同。

### 左侧服务器栏

桌面端对已加入和仅管理信息的服务器图标增加自定义右键菜单。菜单作用于被右键的服务器，不要求先切换到该服务器。键盘用户可在服务器按钮获得焦点后通过上下文菜单键或 `Shift+F10` 打开同一菜单。

左键行为保持不变：已加入的服务器执行切换，仅管理信息的服务器打开平台服务器管理。

### 菜单关闭

点击菜单外、按 `Escape`、切换服务器或开始执行菜单项后关闭菜单。标题菜单锚定按钮显示；右键菜单显示在指针位置，并限制在视口范围内。

## 权限与菜单内容

| 服务器状态与角色 | 管理控制台 | 平台服务器管理 | 离开服务器 |
| --- | --- | --- | --- |
| 普通成员 | 否 | 仅平台管理员 | 是 |
| 服务器管理员 | 是 | 仅平台管理员 | 是 |
| 服务器所有者 | 是 | 仅平台管理员 | 否 |
| 平台管理员尚未加入 | 否 | 是 | 否 |

“管理控制台”使用服务器管理图标。“平台服务器管理”使用平台服务器管理图标。“离开服务器”放在菜单底部，前方有分隔线，图标与文字均使用危险色。

频道列表中现有的“管理控制台”和“离开服务器”入口全部移除，不保留重复入口。

## 非当前服务器操作

### 打开管理控制台

从非当前服务器菜单选择“管理控制台”时，先切换并完成目标服务器的数据加载，再打开管理控制台。加载失败时不打开面板，界面回到原服务器并显示错误，避免页面服务器与管理目标不一致。

### 打开平台服务器管理

从服务器菜单选择“平台服务器管理”时，直接打开该服务器的平台管理详情。桌面端服务器栏顶部的全局平台管理入口继续保留，用于浏览和创建服务器。

移动端已选中服务器时，隐藏原有独立平台管理按钮，通过服务器操作菜单打开该服务器详情；没有当前服务器时保留独立平台管理按钮，确保平台管理员仍能创建、加入和管理服务器。

## 离开服务器

菜单项继续使用“离开服务器”，并以危险色显示。点击后关闭菜单并打开应用内确认对话框，不使用浏览器原生 `confirm`。

确认对话框内容：

- 标题：`离开“{服务器名称}”？`
- 说明：`你的成员身份将被移除，之后需要由服务器管理员重新添加。你发送的历史消息不会被删除。`
- 操作：普通“取消”按钮和危险色“离开服务器”按钮。

提交期间禁用关闭和重复提交。请求失败时保留对话框和成员关系，在对话框内展示错误。请求成功后关闭对话框，不额外显示成功通知。

离开后的状态规则：

- 离开非当前服务器时保持当前页面不变。
- 离开当前服务器时自动选择剩余已加入服务器中的第一个。
- 没有剩余服务器时进入现有的“尚未加入任何服务器”空状态。
- 若语音仍连接在目标服务器，成功移除成员关系后立即断开该语音会话。

## 可访问性

- 菜单触发按钮提供 `title` 和 `aria-label`。
- 自定义菜单使用 `menu`、`menuitem` 语义，并在打开后将焦点移入菜单。
- 支持方向键移动、`Home`、`End`、`Enter`、空格和 `Escape`。
- 菜单关闭后，在触发元素仍存在时恢复焦点。
- 确认对话框使用 `dialog` 和 `aria-modal`，打开后聚焦“取消”，关闭后恢复焦点。

## 验证范围

- 普通成员、服务器管理员、服务器所有者、平台管理员和未加入平台管理员的菜单权限。
- 标题菜单、服务器图标右键菜单、键盘上下文菜单及菜单关闭行为。
- 非当前服务器的管理和离开操作不会错误作用于当前服务器。
- 离开当前、非当前、最后一个服务器以及语音连接所在服务器的状态变化。
- 确认对话框文案、请求中状态、失败展示和历史消息说明。
- 桌面端与移动端服务器标题布局不发生挤压或重叠。
