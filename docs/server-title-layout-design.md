# 服务器标题布局调整

## 背景

频道侧栏顶部同时显示服务器名称和固定副标题“服务器频道”。副标题没有补充有效信息，
反而削弱了服务器名称的视觉层级，并使标题无法在标题栏内垂直居中。

## 设计决策

- 已选择服务器时，仅显示服务器名称，不再显示“服务器频道”。
- 未加入服务器时，继续显示“尚未加入服务器”和“请联系服务器管理员”，保留有效的操作提示。
- 服务器名称字号设为 `16px`。
- 标题栏保持 `49px` 高度，服务器名称在标题栏内垂直居中，继续与相邻顶部栏对齐。
- 保留现有单行截断和右侧服务器操作按钮布局。

## 验收标准

1. 桌面端和移动端的已加入服务器标题栏都不显示“服务器频道”。
2. 服务器名称计算字号为 `16px`，并在 `49px` 高的标题栏内垂直居中。
3. 长服务器名称仍以省略号截断，不与右侧操作按钮重叠。
4. 未加入服务器时仍显示“请联系服务器管理员”。
