# 消息编辑器布局设计

## 目标

修正消息编辑器纵向展开后字数提示和发送按钮垂直居中的问题，并让文本溢出时的滚动条与编辑器整体边界对齐。

## 布局

- 消息编辑器分为上下两层：上方为全宽文本区，下方为固定操作行。
- 操作行始终保留，左侧留空，字数提示与发送按钮靠右排列并固定在编辑器底部。
- 文本区和操作行属于同一连续表面，不使用分隔线。
- 文本区最大高度保持 `144px`；操作行不计入该高度。
- 发送快捷键、`2000` 字限制、禁言状态和发送中状态维持现有行为。

## 滚动条

- 仅当文本超过文本区最大高度时显示滚动条，未溢出时隐藏并保留稳定的滚动空间。
- 滚动条位于整个消息编辑器的最右侧，并在圆角内侧保留约 `4px` 间距。
- 滚动条宽 `6px`，使用透明轨道和圆角滑块，不显示上下箭头。
- 默认滑块保持低对比度；编辑器聚焦或滑块悬停时增强对比度。

## 响应式行为

- 桌面端在操作行右侧显示字数提示和发送按钮。
- 移动端继续隐藏字数提示，但保留操作行，发送按钮固定在右下角。

## 验收条件

- 单行和多行输入下，字数提示与发送按钮始终位于底部操作行。
- 文本区增长至 `144px` 后不再撑高，后续内容可在文本区内部滚动。
- 滚动条不会出现在正文与操作区之间，也不会显示浏览器原生上下箭头。
- 滚动条出现或消失时，正文宽度不发生可见跳动。
- 深色与浅色主题下滑块均清晰但不抢眼。
- 桌面和移动视口下控件不重叠，长文本不会遮挡字数提示或发送按钮。
