# 戳一下用账号定向事件，不从频道消息推导

卡片戳一下没有对应消息；客户端对带 guildId 的事件会丢掉非当前服务器的（含 `message_created`）。两处触发要同一记效果，且每个在线端都要呈现（与当前正在查看哪个服务器无关），因此戳一下走与语音通话相同的账号定向投递（该账号全部连接），不靠接收端扫描消息是否点名了自己。提及仍随消息进入频道历史；离线目标只留下消息中的提及，不补送戳一下。

事件带上发起人 id 与当时的全局显示名。目标端成员名单只有当前服务器，不能在提示的 4 秒内去查另一个服的人；通话信令对对端也是同一做法。显示名不另存历史——没有收件箱，下一次事件用新名。

正在查看该频道时，要用「这记戳一下发没发出去」在新文字消息音效和戳一下音效之间二选一。该标记只出现在发给接收者自己的实时 `message_created` 上，不进历史、不出现在频道里其他人的副本里——否则要么把戳一下写进历史，要么向全频道泄露谁被戳到。提示与戳一下音效仍只由账号定向事件产生；卡片戳一下没有对应消息。同一条连接上两件事紧挨着，丢一件当传输失败。
