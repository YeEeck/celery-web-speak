# 简介与平台在线时长挂在全局 User，服务器在线时长暂不做

新增的用户自我表达（简介）与平台在线时长都是"我是谁 / 我用了多久"的全局属性，挂在 `users` 表上、跨服务器一致，与既有"头像属于全局 User"的边界保持一致。服务器在线时长因依赖"活动服务器切片"而无当前 activeGuild 上报来源，暂不实现，待 activeGuild 落地后再议。

## Considered Options

- **简介每服务器 GuildMember 一份**：被否。语义偏"成员名片"而非个人简介，体量不值得为每个服务器维护一份独立简介。
- **服务器在线时长用"成员在服即算"切片**：被否。同时加入多个服务器的成员，在线 1 小时会让各服之和超过平台在线时长，不自洽，且不区分"在哪个服花时间"。
