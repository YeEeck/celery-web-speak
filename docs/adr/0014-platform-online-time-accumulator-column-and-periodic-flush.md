# 平台在线时长用 users.online_seconds_total 内存累加 + 周期落盘

在线时长以整秒累加在 `users.online_seconds_total` 列上，由 Hub 在 `counts` 0↔1 在线转换时结算、跨设备合并不重复计，配合约 60s 周期对账落盘与优雅停机整体落盘。不使用持久化区间表，因为个人信息卡片只展示一个累计秒数，不值得区间表的写入与清理成本。最坏丢失约为一次重启前的飞行段（约 60s），可接受。

## Considered Options

- **presence_intervals 持久化区间表**：可回溯、可做日/周分布图，但写入、清理与聚合成本对"只展示一个总和"是过度工程。若将来需要分布视图，可在此架构上增表，不破坏现有累加路径。
