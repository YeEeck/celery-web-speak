# 推翻"不加载外部音频文件"原则、允许用户上传自定义提示音

`docs/product-spec.md` 原则上写明操作提示音"不依赖外部音频地址，也不仿制第三方产品音效"，`docs/architecture.md` 进一步强调"由 Web Audio Oscillator/GainNode 本地合成，不加载外部音频文件"。该原则在只提供系统预置音效时合理，但用户缺少个性化提示音的能力，也无法试听预置。

本次决定推翻该原则：除系统预置音效（继续由 Web Audio 本地合成）外，新增"自定义音效"——用户为本机浏览器上传一个音频文件（MP3、WAV、OGG、M4A 或 WEBM，大小 ≤ 512 KB，时长 ≤ 3 秒），由 `decodeAudioData` 解码后通过 `AudioBufferSourceNode` 播放。原始 Blob 存于浏览器 IndexedDB，不上传服务器、不同步到其他浏览器。

考虑过的替代方案：让用户在应用内编辑音符模式延续合成模型——零存储成本、零格式限制，但用户无法使用其已拥有的现成音频文件，与"自定义提示音"的用户心智模型相去甚远。最终采纳用户上传音频文件方案，并接受相应规格与架构文档的修订。
