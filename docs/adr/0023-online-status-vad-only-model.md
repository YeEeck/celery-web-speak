# 在线状态采用"自动/固定离开"两态模型，自动检测信号仅用语音活动

在线状态此前形同虚设：绿点只表达 WebSocket 连接存活，用户既不能手动设置，程序也不自动监听。决策：在线状态是全局用户态（跨服务器一致），只有在线与离开两态；状态设置两值——自动模式（默认）与固定离开，固定离开时自动检测暂停；自动模式下由本机语音说话活动驱动（连续 10 分钟无一次连续约 600 毫秒的说话活动进入离开，恢复说话立即回在线），阈值固定不提供设置。

信号源明确拒绝本地交互事件（指针/键盘）方案：产品是语音协作工具，"在场"的语义锚定在说话上；麦克风权限在登录进入应用时即已请求（AppShell 挂载），语音信号覆盖近乎全员，无需为交互事件付出语义噪声代价。离开状态与平台在线时长解耦——时长仍按连接累计，不受状态影响。
