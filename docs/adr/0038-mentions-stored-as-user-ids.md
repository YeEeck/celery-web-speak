# 提及按用户 id 随消息保存，不扫描正文

文字消息引入提及时，正文仍展示 `@登录名`，但点名对象以用户 id 名单另存。诚实客户端只把补全插入的人放进名单；服务端不发明令牌去证明来自补全，只校验活跃成员、不是作者、最多 10 个不重复、正文里确有对应 `@登录名`。手打且不带 id 仍是普通字符。功能上线前的旧消息没有名单，不高亮、不补扫。

登录名不可改，扫正文在多数时候也能对上人；但退服、封禁、删号后再注册的同名账号会把旧字面指到别人或无处可指。点名的是人，不是当时的字符串。读回带登录名快照，是为了退服成员不在当前成员名单里时仍能高亮；已删除账号从名单里拿掉，避免登录名释放后点到新人。
