# 戳一下冷却按账号对全局计，卡片与提及共用，本进程内存

同一对发起人→目标 10 秒内只成功一记，不论从个人信息卡片还是从提及发放。否则发一条点名同一人的消息就能绕开卡片冷却。发起人另有总闸：10 秒内最多 8 记成功，避免点遍成员名单。一条消息按点名名单从头走，能成功的才占窗口；离线、已删、已在一对人窗口里的跳过且不占总闸。窗口内卡片再点下去报「戳得太频繁」；资格失败（退服、封禁等）报「现在不能戳」，不向发起人区分原因；提及则消息照发、戳一下静默丢掉，避免「消息已发出」之后再弹一条失败。失败（离线、不是活跃成员、资格）不占窗口。目标端若正在查看该频道、但这记因冷却未发放，按普通新消息播新文字消息，不把这条点名消息变成静音。

计时落在服务端本进程内存，与文字消息 8/10 秒同一档。本产品没有多实例部署，不为冷却引入共享存储。进程重启后窗口归零，与发消息频率同一取舍。多端共享这一窗口，是因为戳一下走账号定向事件，两端同时点会打到同一人。
