# 语音快捷键在文本输入期间仍然生效

语音快捷键（`Ctrl+Shift+M` 切换麦克风静音、`Ctrl+Shift+D` 切换耳机静音）在已登录主界面的任何焦点位置都生效，包括焦点位于消息编辑器正在打字时。这与多数 Web 应用"输入框内抑制全局快捷键"的惯例相反，但语音应用的核心场景是紧急闭麦——它往往发生在说话中途，此时用户焦点通常仍在聊天输入上；`Ctrl+Shift` 组合不产生可打印字符，拦截它不会吞掉文字输入，Discord 桌面端与 Web 端均采用相同行为。代价是存在误触可能，但麦克风静音可随时再按一次恢复，后果轻微且即时可逆；一旦用户形成肌肉记忆后再改为输入时抑制，将破坏已建立的操作预期，因此本决策不易反转。模态弹窗（`aria-modal="true"`）打开期间不拦截，以保持模态焦点管理语义不被穿透。
